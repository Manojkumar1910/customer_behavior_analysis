## 🧭 Project Overview

This project explores customer purchasing patterns using a retail shopping dataset. The goal is to uncover actionable business insights around revenue, customer loyalty, product performance, and discount behavior — using a full analytics stack: **Python**, **SQL**, and **Power BI**.

## 🎯 Business Questions Answered

| # | Question |
|---|----------|
| 1 | What is the total revenue generated by male vs female customers? |
| 2 | Which discounted customers still spend above average? |
| 3 | Which are the top 5 highest-rated products? |
| 4 | Does shipping type (Standard vs Express) affect average spend? |
| 5 | Do subscribed customers spend more than non-subscribers? |
| 6 | Which products have the highest discount usage rate? |
| 7 | How are customers segmented by loyalty (New / Returning / Loyal)? |

## 📁 Dataset

**File:** `customer_shopping_behavior.csv`

The dataset contains transactional and demographic data for retail customers including:

- `customer_id` — Unique customer identifier
- `age`, `gender` — Demographics
- `item_purchased`, `category` — Product details
- `purchase_amount` — Transaction value (USD)
- `review_rating` — Customer satisfaction score (1–5)
- `subscription_status` — Whether the customer is subscribed
- `discount_applied` — Whether a discount was used
- `shipping_type` — Standard or Express
- `previous_purchases` — Number of past transactions

---

## 🔍 Key Insights

- 💰 **Revenue by gender** is nearly balanced, with slight differences across product categories
- 🎁 **Discounted customers** who still spend above average represent a high-value segment worth targeting
- ⭐ **Top-rated products** don't always overlap with best-sellers — quality vs. quantity gap
- 🚚 **Express shipping** customers tend to have marginally higher average spend
- 🔁 **Subscribed customers** generate significantly more total revenue despite similar average spend
- 👥 **Loyal customers** (10+ purchases) form a small but disproportionately high-revenue segment
- 📦 **Discount rate per product** reveals which items rely on promotions to drive sales
- 👴 **Age group 35–50** contributes the highest share of total revenue

## 🚀 How to Run

### Python Notebook

1. Clone this repository:
   ```bash
   git clone https://github.com/Manojkumar1910/customer_behavior_analysis.git
   cd customer_behavior_analysis
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook:
   ```bash
   jupyter notebook Shopping_Customer_Behavior_Analysis_project.ipynb
   ```

### SQL Queries

1. Import `customer_shopping_behavior.csv` into a MySQL database named `customer_behavior`
2. Run the queries in `customer_analysis.sql` using MySQL Workbench or any SQL client

### Power BI Dashboard

Open `customer_behavior_dashboard.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
